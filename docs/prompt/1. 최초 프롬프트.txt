아래 내용을 기준으로 모호성이 있는 내용이 있다면 검토해서 알려줘. 모호성이 해결된다면 계획 플랜을 세울거야. 전체적으로 확인해줘

1. 숙소 정보는 1일차에서 5일차까지 동일한 숙소인데, 1일차에만 보이고 있음
2. 숙소 체크인 시간과 체크아웃 시간을 지정할 수 없음. 이것은 비행기도 마찬가지고 다른 일정들에도 포함됌. 시작 시간만 지정할 수 있음.
3. 업로드 된 미디어에 대한 메타데이터 및 폴더 이동 등 수정 권한이 없음
4. 폴더로 이동 후, 미디어를 가지고 오는 기능이 없음. 폴더에 지정이 되었던 안되었던 가지고 오는 임포트 기능이 있으면 좋겠음. 실제로는 폴더만 이동될 뿐임.
5. 문서에 대한 저장버튼이 존재하지 않음. 추가적으로 저장이 되었다면 수정 기능이 존재해야된다.
6. 설정에서 기본적으로 해당 모임의 통화 설정이 잘못된 경우가 있을 수 있으니, 수정 기능이 존재하면 좋을 거 같음.
7. 공유된 링크를 보면, 로그인이 안되었거나 해당 모임에 포함되지 않은 사용자는 뷰어 페이지로 가는 게 맞아. 하지만, 미디어 폴더 공유시에는 모임이 존재해도 뷰어 페이지가 보이고 있는 상황이야. 그리고, 뷰어 페이지에서는 로그인을 하거나 로고를 클릭하는 방식으로 뭔가 이벤트를 주면 좋겠어. 로그인을 해서 뷰어가 아닌 모임으로 들어간다던가, 뷰어 페이지는 다 봤으니, 다른 모임으로 간다던가 등등 하면 좋겠어.
8. 모임 바꾸기 기능에서 모임 바꾸는 게 아닌 신규 모임 생성은 존재하지만, 모임 들어가기인 URL 입력 기능이 시작 페이지랑 다르게 되어 있어. 이것도 같은 시작페이지처럼 URL 접속 기능 있으면 좋겠어. 대신 여기에서는 바로 이동하는 게 아니라, 생성이든 가입이든 모달창 안에서 "생성/가입 되었습니다" 같은 메세지로 모달창을 보여주고, 이동 버튼 누르면 해당 모임으로 접속하는 거고, 모달을 닫으면 모임 바꾸기 눌렀을 때 해당 모임이 보이도록 처리히면 될 거 같아
