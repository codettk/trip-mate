# 작업 방식 — 멀티에이전트 운용

이 저장소는 **여러 에이전트가 동시에** 손대는 걸 전제로 만들어졌다.
그래서 규칙 대부분이 "누가 어느 파일을 쓰는가"와 "무엇을 실행해 증명하는가"에 관한 것이다.

## 왜 이렇게 하는가

TripMate 의 확정 규칙은 대부분 **조용히 틀릴 수 있는 것**들이다.
정산에서 나간 멤버를 빼면 화면은 멀쩡한데 잔액 합이 0이 아니게 되고,
뷰어에 조상 폴더 토큰을 허용하면 아무도 에러를 못 보는 채로 사진이 샌다.
그래서 리뷰가 아니라 **실행해서 증명하는 문지기**를 따로 뒀다.

## 에이전트

`.claude/agents/` 에 정의돼 있다.

| 에이전트 | 언제 | 무엇을 |
|---|---|---|
| **api-module** | API 도메인 모듈 하나를 만들거나 고칠 때 | 라우트 + zod + Kysely. 배정받은 파일만 |
| **web-screen** | 화면 하나 또는 모달 묶음 | React + 확정된 디자인 시스템 |
| **settlement-guard** | 금액·통화·환율·멤버·정산 대상을 건드린 뒤 | 불변식 3종을 **실행해서** 확인 |
| **share-auditor** | 공유·뷰어·미디어·저장소를 건드린 뒤 | 유출 경로를 찾아 보고 |

뒤의 둘은 **고치지 않는다.** 찾아서 보고만 한다. 고치는 사람과 검사하는 사람이 같으면
자기가 만든 가정을 그대로 통과시킨다.

## 병렬로 돌릴 때의 철칙

**1. 파일 경계를 먼저 못박는다.**
에이전트를 띄우기 전에 "너는 이 파일들만 만든다"를 정해 준다.
공유 파일(`app.ts`, `db/*`, `services/*`, `auth/*`, `styles/app.css`)은 아무도 건드리지 않는다.
바꿔야 하면 고치지 말고 보고하게 한다. 안 그러면 서로를 덮어쓴다.

**2. 계약을 먼저 쓴다.**
`docs/API.md` 와 `packages/core/src/types.ts` 가 그 계약이다.
계약이 없으면 병렬로 만든 조각이 안 맞는다. 계약을 쓰는 데 든 시간이 항상 더 싸다.

**3. 크로스커팅은 오케스트레이터가 직접 쓴다.**
정산 코어, DB 스키마, 인증, 저장소 어댑터는 나눠 주지 않는다.
이것들이 어긋나면 전부가 어긋난다.

**4. "타입체크했습니다"를 믿지 않는다.**
받은 결과는 오케스트레이터가 다시 돌린다. 다른 에이전트가 만드는 중인 모듈 때문에
`Cannot find module` 이 섞여 나오므로, 각자는 자기 파일의 에러만 판단할 수 있다.

**5. 보고는 짧게, 판단만.**
잘된 것을 길게 쓰지 말고 **판단이 필요했던 지점과 근거**, 그리고 통과 못 한 것만 쓰게 한다.

## 무엇을 실행해서 증명하는가

```
npm run test -w @tripmate/core     # 정산 알고리즘 — 프로토타입 재현 + 무작위 1000케이스
npm run test -w @tripmate/api      # API 통합 — 실제 Postgres 에 붙는다
npm run test -w @tripmate/web      # 화면 렌더 + 확정 규칙 감사
npm run typecheck                  # 전 workspace
npm run seed -w @tripmate/api      # 시드가 기대 잔액표를 그대로 찍는지
```

정산을 건드렸으면 **잔액 합 0 · 이체 합 일치 · 전부 정수** 셋을 실제 출력으로 확인한다.
공유를 건드렸으면 "Drive 링크를 노출하고 있지 않은지", "문서를 외부로 내보내고 있지 않은지"
먼저 확인한다.

## 새 기능을 붙일 때

1. **새 페이지가 필요한지 다시 생각한다.** 대부분 모달이나 인라인으로 된다.
2. 화면을 새로 만들면 프로토타입(`prototype/index.html`)과 Pencil 디자인
   (`docs/design/pencil/trip-mate-prototype.pen`) 양쪽을 같이 갱신한다. 둘이 어긋나면 기획이 흔들린다.
3. 애매한 것은 **고민하지 말고 판단하되 반드시 기록한다** —
   `docs/decisions/` 에 "무엇을 정했고 왜, 뒤집는 비용은 얼마"를 남긴다.
